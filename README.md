# MPOSystem
Мобильное Приложение Обучающей Системы (МПОС) предназначено для автоматизации учебного процесса определнного предмета, с целью более удобного получения необходимых знаний и доступности материалов. В будущем планируются реализация автоматической обработки docx файлов и построение интерфейс на основе содержимого методических указаний без участия пользователя.
Stack:
Front on Android Kotlin: https://github.com/ThePerfomance/MPOSystem
Server on Rust, BD PostgreSQL: https://github.com/Yaosobolev/web-programming-tutorial
