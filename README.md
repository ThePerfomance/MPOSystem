MPOSystem — мобильное приложение обучающей системы (МПОС) для автоматизации учебного процесса. 

В данном приложении представлены такие функции как:
-Регистрация/Вход пользователей;
-Просмотр методических указаний ( Лекции, практические и лабораторные работы );
-Прохождение тестирования по заданным дисциплинам;
-Анализ результатов тестирования с помощью ML-алгоритмов;
-Генерирование отчёта и персональных рекомендаций студенту/преподавателю.

Кластеризация студентов по рангам, сегментация тестов по уровню сложности на основе результатов тестирований студентов, прогнозирование будущих результатов прохождений и с использованием выводов трех ml-алгоритмов создание персональных рекомендаций по изучению материала.

Технологии проекта:
📱 Android-клиент: Kotlin, MVVM, Retrofit, Coroutines.
⚙️ Сервер: Python, Django REST Framework, PostgreSQL, Docker.
🎨 Дизайн: Figma, Material Design 3.
